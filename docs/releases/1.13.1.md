# OpenOSRS 1.13.1

OpenOSRS now targets the RuneLite 1.13.1 release and Old School RuneScape revision 241. The client and API release number now follows the RuneLite version it targets. Launcher versions remain independent.

## Community changelog

- **Back up to date**
  The client and API now match RuneLite 1.13.1 and the current game revision.

- **Updated game data and interactions**
  Refreshed interface IDs, packet mappings and launch compatibility for this build, while keeping the OpenOSRS plugin and human mouse features.

- **Correct prices for expensive items**
  Grand Exchange offers, item prices and value displays now handle amounts above the old 32-bit limit. This also fixes the price download failing when the market contains an item over that limit.

Plugin developers: rebuild against the new API if you use Grand Exchange prices or spending totals; those values now use `long`.

## Client and API changes

- Pin the exact official RuneLite 1.13.1 injected client and revision 241, with SHA-256 verification during builds.
- Regenerate packet and account mappings from those bytes. Refresh the normal stock-launch call stack for the same release.
- Import the matching RuneLite API changes, game IDs and client-script sources, retaining OpenOSRS extensions.
- Add upstream 64-bit varplayer access and long-valued varbit events; keep the legacy integer varbit helper.
- Carry 64-bit prices through OpenOSRS Grand Exchange snapshots, saved offers, HTTP price data, item values and risk calculations.
- Bind inventory, widget, amount-input and prayer services to revision 241 and its interface IDs.
- Delay cannon startup state reads until a game session is logged in.

## Compatibility and scope

The release retains OpenOSRS-owned plugins and UI. It is an independent client based on RuneLite, not an official RuneLite distribution.

The packet inventory accounts for all 102 outgoing slots: 82 verified layouts, five zero-length packets, six unreferenced slots and nine unresolved layouts. Unresolved layouts stay disabled. These counts describe static mapping coverage, not gameplay coverage.

The release ABI check retains 31 pre-existing deferred native obligations, with no new missing signatures. Full native API compatibility and every gameplay operation are not claimed.

## Installation

Use the existing [OpenOSRS Launcher](https://github.com/OOSRS/OOSRS-Launcher/releases/latest) and select **Check updates**, then **Launch OpenOSRS**. A launcher upgrade is not required. New installs require Java 11 or newer to open the launcher; it downloads its own client runtime.

Direct launch: `java -jar openosrs-client-1.13.1.jar`.

This release includes the client, API and source JARs, API documentation, `SHA256SUMS`, and the launcher's verified update metadata.

## Release validation

- Existing release contracts passed: 795 client checks and 206 API checks, with no failures.
- Independent reference encodings passed 248 samples across 62 outgoing packet IDs.
- The release ABI gate passed its pinned baseline with no new missing signatures.
- The candidate initialized on the launcher's downloaded Java 11 runtime, loaded revision 241 hooks and displayed the native first-launch screen without startup errors. No game account was logged in.
