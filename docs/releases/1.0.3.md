# OpenOSRS 1.0.3

Profiles is now in the sidebar. Add your Jagex accounts, choose a character, and log in.

- Add, reconnect, and remove saved accounts.
- Search characters, set favourites, and rename account labels.
- Keep saved sessions encrypted on your device, or use session-only mode.
- Complete browser sign-in on Linux without root access.
- Cleaner text and properly sized account dialogs.

Login tested on Linux. Windows and macOS testing is still pending.

Open the launcher and check for updates to get 1.0.3. Direct JAR users can download `openosrs-client-1.0.3.jar` below.

Still RuneLite 1.12.38 / revision 240 / Java 11. [Profiles guide](https://github.com/OOSRS/OOSRS/blob/v1.0.3/docs/PROFILES.md).
