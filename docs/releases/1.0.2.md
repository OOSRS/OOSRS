# OpenOSRS 1.0.2

Client update for RuneLite 1.12.38 / game revision 240. Java 11 remains the build and minimum runtime target. Use the current OpenOSRS Launcher for automatic client downloads and a compatible Java runtime.

## Changes

- Updated Plugin Hub compatibility and external plugin installation, update, rollback, and shutdown handling.
- Repaired native action routing and checked packet encoders against independent nonzero wire fixtures. Unverified layouts remain disabled.
- Added owned operation lifetimes, shared input coordination, cancellation on plugin stop or manual input, and stale entity/item/widget checks.
- Reworked banking, trade, shop, Grand Exchange, dialogue, Make-X, spell selection, and movement helpers around current native contracts.
- Updated the GPU renderer and built-in plugin API usage for the pinned client.
- Fixed game configuration downloads, startup parsing, and prayer drain estimates.
- Included API/source JARs, versioned Javadocs, and build checks that reject new runtime interface gaps.

## Plugin compatibility

The release still has **32 deferred native method obligations, covering 21 distinct signatures**. Plugins must avoid these legacy methods:

- `Renderable.draw(int, int, int, int, int, int, int, int, long)` (missing on 12 concrete game classes).
- `Client.getStringStack()`, `getStringStackSize()`, `setStringStackSize(int)`; use the object stack APIs.
- `Client.getCameraX2()`, `getCameraY2()`, `getCameraZ2()`; use supported camera accessors.
- `Client.setPrintMenuActions(boolean)`.
- Legacy `Client.getVar(...)` and `setVar(...)` overloads for `VarPlayer`, `VarClientInt`, and `VarClientStr`; use the corresponding native varp/varc APIs.
- `Client.setInterpolatePlayerAnimations(boolean)`, `setInterpolateNpcAnimations(boolean)`, and `setInterpolateObjectAnimations(boolean)`; optional animation smoothing is unavailable on this artifact.
- `Client.getIf1DraggedItemIndex()`, `getItemPressedDuration()`, and `getIf1DraggedWidget()`; inventory overlays use the current drag APIs.
- `ScriptEvent.setSource(Widget)`.

The exact gamepack and obligations are pinned in [the deferred compatibility list](../../config/runtime-abi-deferred.json). The strict ABI check remains available and fails on this known debt; the release check reports the debt and rejects new failures or a different gamepack.

Build and bytecode checks do not prove server acceptance of every action. The prior candidate reached the pre-login screen with GPU rendering on Linux; full in-game and Windows/macOS checks remain outstanding.

## Updating

Reopen the launcher and select **Launch OpenOSRS**, or use its update check. Its client channel downloads `openosrs-client-1.0.2.jar` and verifies the published SHA-256 before caching it. Launcher 1.0.4 already supports this client update; no launcher version bump is required.

Direct JAR users must download this version themselves. Version 1.0.1 stays available as a rollback for this same game revision.
