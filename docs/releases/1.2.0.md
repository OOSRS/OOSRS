# OpenOSRS 1.2.0

Two big things in this one: the client is up to date with RuneLite 1.12.39, and
plugins built on the OpenOSRS API can now act through a real, moving mouse
instead of submitting interactions directly.

## Human mouse

Open **Mouse settings** in the plugin list and switch on *Use the human mouse*.
From then on, anything a plugin does through the OpenOSRS API is carried out by
a cursor that moves, hesitates, aims and clicks the way a hand does. Clicks only
land after the menu under the cursor has been checked against what the plugin
asked for, so a moving target or a changed menu does not turn into a wrong
click.

It is off by default and nothing moves unless a plugin asks. A few things hold
no matter how it is set up:

- Your own mouse and keyboard always win. Touching either cancels idle or
  preparatory movement straight away.
- Idle movement only happens during an automation session, and only after you
  have left the mouse and keyboard alone for 30 seconds.
- A near miss never clicks. The cursor settles beside the target, then corrects.

Movement comes from profiles you can train on your own mouse use with *Learn
mode*. Recordings stay on your computer.

If you want to watch it work, the overlay can draw the cursor's own pointer with
a ripple where it clicks, a short trail, and corner marks on whatever it is
heading for. All of that is off by default, and the pointer fades out a moment
after the cursor stops so it never sits next to yours.

Plugin authors can pin one call or a whole block to a delivery mode with
`InputScope`, and the full picture is in [docs/HUMAN_INPUT.md](../HUMAN_INPUT.md).

## RuneLite 1.12.39

Still revision 240, but a freshly obfuscated build, so every hook was
re-derived and checked against the previous build. The main visible change on
our side is login: this build keeps login credentials in a different shape,
and OpenOSRS now reads and writes them through small accessors it generates
when the game loads.

Upstream fixes and additions that came along:

- Timers recognise the new freeze message.
- The cannon plugin reads the decay state from the game.
- Interact highlight follows the actor you are actually interacting with.
- Attack styles no longer breaks the special attack bar when it hides auto retaliate.
- Item identification knows the sap-treated logs and the new tablets and scrolls.
- The skill calculator covers Sailing and the fishing bonuses.
- Item variations are refreshed.

## API

- **Grand Exchange search results.** `searchResults()` lists what the search
  shows under the prompt, and `selectBuyItem` picks from it by id or name. An
  exact name now wins over a partial one, so "Rune platebody" no longer lands
  on "Rune platebody (g)". With the human mouse the cursor scrolls the list to
  the item first.
- **Spells on inventory items.** `castOn(spell, inventoryItem)` works from the
  spellbook now. It used to insist the inventory was on screen before the spell
  was even selected, which it never is.
- **Chatbox item search.** `DialogueService.searchResults()` and `choose()` for
  "choose an item" prompts, sharing the same reading of the result list.
- `InventoryService.requireHeld(item)` checks an item is still in its slot
  without requiring the inventory tab to be open.
- `openSlot` on the Grand Exchange no longer clicks a slot button before the
  game has given it its action.

## Packets

`MESSAGE_PUBLIC`, `MOVE_MINIMAPCLICK` and `EVENT_MOUSE_MOVE` are quarantined
again. Their write sequences were marked verified in 1.1.0, but checking them
against reference decoders showed the variable-length layouts were incomplete,
so nothing encodes against them until they are proven. Trusted layouts go from
95 back to 92 of 117. Nothing else about packet coverage changed.

## Testing

Contract and binary-compatibility gates pass: 627 client tests and 206 API
tests, no failures. Beyond that, this build was run against a logged-in 1.12.39
client: login, then bank, Grand Exchange and walking through the human mouse,
then a full script that bought supplies on the Grand Exchange, set up the
inventory and cast High Alchemy 26 times without a hand on the mouse.
