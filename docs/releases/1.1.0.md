# OpenOSRS 1.1.0

A plugin-facing release. Most of what changed is API surface rather than
anything you will see on screen.

## Grand Exchange API

Plugins can now drive the Grand Exchange through `GrandExchangeService` instead
of hand-rolling widget clicks:

- Open, close and go back; check whether the interface is open or searching.
- Search, and select a buy item by id or by name.
- Adjust price and quantity through `PriceAdjustment` and `QuantityAdjustment`.
- Collect and abort by slot, open offer details, and retry an offer at a higher
  price.

`MovementService` gains `walkTo(WorldPoint, ctrl)`. `AmountInputService` now
routes through the packet dispatcher. Widget and dialogue services follow.

## Packet coverage

Three variable-length outgoing packets that the layout extractor had
quarantined now carry verified write sequences: `MESSAGE_PUBLIC`,
`MOVE_MINIMAPCLICK` and `EVENT_MOUSE_MOVE`. Trusted layouts go from 92 to 95 of
117 opcodes.

`UPDATE_PLAYER_MODEL_V2` deliberately still carries no layout. Its emit path
writes 20 bytes against a declared length of 26, and that gap is unexplained, so
it is recorded as unresolved rather than shipped as a mapping. Nothing encodes
against it.

The remaining opcodes without layouts are not gaps: 21 of them are declared in
the packet table and have no call sites anywhere in the game client.

## Live debug endpoint

A new `--livedebug [port]` flag starts a loopback JSON-RPC endpoint for
maintainer tooling. It is off unless you pass the flag, binds `127.0.0.1` only,
and authenticates against a per-session token. It is not reachable from the
network and does nothing in a normal launch.

## Profiles

The profiles panel has been reworked: cleaner layout, better search, and tidier
account dialogs.

## Testing

Contract and binary-compatibility gates pass: 607 client tests and 188 API
tests, no failures. The Grand Exchange and live debug work has unit coverage but
has not yet been exercised end to end against a logged-in client, so treat those
two areas as new.

Open the launcher and check for updates to get 1.1.0. Direct JAR users can
download `openosrs-client-1.1.0.jar` below.
